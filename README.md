# Hüttenheim Nebenkosten

Nebenkostenabrechnung, Jahresabschluss und Steuerübersicht für Haus 1, Haus 2 und Friseursalon.

- Läuft im Browser und offline, als App installierbar: https://endem61.github.io/Nb-6e1d/
- Die Daten liegen **nur im Gerät** und – wenn verbunden – auf dem eigenen M920q (CouchDB-Add-on „SEEN Datenbank“, Datenbank `nebenkosten`, nur über Tailscale). Keine Hausdaten in diesem Repository.
- Sicherung: Einstellung → Komplette Sicherung (JSON), am besten in den OneDrive-Ordner.
